4. **Aplicações desconectadas** — modelo de governança para aplicações sem conector nativo, com registro em banco dedicado;
5. **Integração Jira** — abertura e acompanhamento automático de chamados para provisionamentos que dependem de ação manual;
6. **Integração Microsoft Teams** — notificações diretas a solicitantes, aprovadores e gestores, em complemento ao e-mail e ao portal;
